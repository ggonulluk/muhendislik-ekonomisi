# Mühendislik Ekonomisi ve Yatırım Analizi

Programı açmak için: **https://ggonulluk.github.io/muhendislik-ekonomisi/**

Bu depo yalnızca programın yayınlanmış tek dosyalık sürümünü (`index.html`) içerir.
Program tamamen tarayıcıda çalışır; hesaplar ve girilen veriler bilgisayarınızda veya telefonunuzda kalır, hiçbir sunucuya gönderilmez.

- Bilgisayarda: bağlantıyı açın ya da `index.html` dosyasını indirip çift tıklayın (internet gerekmez).
- Telefon ve tablette: bağlantıyı tarayıcıda açın.

Sonuçlar girilen varsayımlara dayanır; karar destek amaçlıdır, yatırım tavsiyesi değildir.
